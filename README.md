# 慢慢会说 · English practice studio

Leo 与 Nico 的本地优先英语学习工作台。两人各有 52 周不同课程，共 104 篇原创微课、520 道带解析练习、520 个词块，以及逐周口语、写作和工作场景。每周七种活动沿同一主题推进，不再从材料字符串猜测任务。

另有35个逐页核验的 British Council 具体原声课，按主题与难度分配到两人各52周。复用材料是间隔复听，不冒充未见题测评；每项明确预习、隐藏文本听原声、原站做题和纠错步骤。

## 使用

在项目目录运行 `python3 -m http.server 4173 --bind 127.0.0.1`，打开 `http://127.0.0.1:4173/`。无需安装第三方包。请使用 HTTP 本地预览，不依赖 `file://` 下的存储、音频和 fetch 行为。

- 今天：当前学习日、核心25分钟、外部真实材料与迁移练习预算、补学入口。
- 学习路线：阶段 → 周 → 学习日。预览不会改变当前学习周；偏好中可调整起点。
- 专注练习：读懂 → 练习 → 留下成果。英文产物、题目解析、实际分钟和下一次动作连在一起。
- 材料库：本周资源、分类搜索、自定义材料与外部练习记录。
- 复习：词块加入第1、3、7天复习，不熟时顺延；不会把“眼熟”自动标记为掌握。
- 成长记录：实际投入、作品与独立测评。未测评显示空状态，不显示虚构基线。
- 学习偏好：开始日期、每周预算、考试类型、四项基线与备份恢复。

`?plan=leo` 和 `?plan=nico` 选择学习者；`#lesson/1/1` 定位第1周第1天。旧的 `#roadmap` / `#materials` / `#records` 路由继续兼容。

## 课程与测评边界

课程级别是内容难度标签，不是对学习者的评级。原创微课和复习题不是 IELTS 真题，正确率不换算雅思分。浏览器合成朗读用于辅助读音；真实听力使用明确标注的原站资源。写作和口语的正式提分判断需要可靠评分，AI反馈仅作训练。

每周300–1500分钟可配置。默认750分钟×52周=650小时，日预算精确汇总为周预算。核心之外的时间明确分配给真实材料、迁移输出和重做；不把预计分钟自动写成实际学习时长。完整模考替代当周第6天常规任务，独立预留165分钟；纸笔听力誊写、评分与复盘按实际需要另安排。未确定考试类型时不允许标记完整模考完成。

## 数据与迁移

文字数据分别保存在 `english-studio:leo:v2` / `english-studio:nico:v2`。同一域名、同一浏览器下首次访问会保留并迁移旧版日志、成绩、自定义材料和任务档案；原始旧键不删除。旧任务与新课程语义不同，不自动变成新版完成状态。

备份校验版本、人物、日期、数值、课程编号及链接；不接受跨人物备份。无人物标识的旧版文件须在界面确认归属。导入和重置前保留 `:before-replace` 快照，损坏数据不会被静默覆盖。清理浏览器、更换设备或更换域名前，先导出JSON；跨域数据需要手动导出/导入。

麦克风仅在用户点击录音时请求；音频保存在本机 IndexedDB 的 `english-studio-audio`，不上传。JSON不含音频，需单独下载。替换现有录音前有提示。计时使用实际时间差，离开页面自动暂停，且始终归属启动时的课程。

Duolingo仅使用公开资料快照，字段白名单不变；不保存密码、Cookie、Token、位置、联系方式或完整接口响应。接口并非官方保证的API，课程分数依旧手动记录。XP与连续学习天数不代表语言能力。
