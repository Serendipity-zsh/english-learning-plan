# English Learning Plan

从高 A1 到雅思 6.5 的 52 周英语学习计划。网站包含逐日任务、量化验收标准、学习材料、有效时长记录、成绩记录、本地备份，以及 `Leo_zsh` 的 Duolingo 公开学习进度。

## 本地预览

项目是无第三方运行依赖的静态网站，可以直接打开 `index.html`，或在项目目录启动任意静态文件服务器。

## 数据与隐私

学习记录保存在当前浏览器的 `localStorage`，不会提交到 GitHub。请定期在“学习记录”页面导出 JSON 备份。清除浏览器数据或更换设备前必须先导出备份。

Duolingo 同步仅调用无需登录的公开资料接口，并通过字段白名单保存用户名、显示名、连续学习天数、总 XP、英语 XP、课程标识和同步时间。不会保存密码、Cookie、Token、位置、联系方式、账号状态或完整接口响应。该接口不是 Duolingo 官方承诺的开发者 API，若临时失效，网站会继续使用仓库中的最近一次脱敏快照。Duolingo Score 当前无法从该公开接口可靠获取，仍在“学习记录”中手动填写。

## GitHub Pages

仓库包含 Pages 工作流。推送到 `main` 后，在仓库的 Settings → Pages 中选择 GitHub Actions 即可发布。工作流每天北京时间约 06:17 自动刷新一次 Duolingo 公开进度，也支持手动运行；定时任务可能受 GitHub Actions 调度延迟影响。
