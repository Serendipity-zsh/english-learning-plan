# English Learning Plan

从高 A1 到雅思 6.5 的 52 周英语学习计划。网站包含逐周任务、量化验收标准、学习材料、有效时长记录、成绩记录和本地备份。

## 本地预览

项目是无第三方运行依赖的静态网站，可以直接打开 `index.html`，或在项目目录启动任意静态文件服务器。

## 数据与隐私

学习记录保存在当前浏览器的 `localStorage`，不会提交到 GitHub。请定期在“学习记录”页面导出 JSON 备份。清除浏览器数据或更换设备前必须先导出备份。

## GitHub Pages

仓库包含 Pages 工作流。推送到 `main` 后，在仓库的 Settings → Pages 中选择 GitHub Actions 即可发布。
